# It works!

Your **Samizdat** installation is running.

This is the default page that ships with Samizdat core. To publish your own site,
point `paths.content` in `samizdat.yml` at your site's content repository (a
`*.com-src` repo holding a `public/` content tree), and enable the plugins you need
under `extraplugins`.

Learn more at the [Samizdat documentation](https://samizdat.foundation/documentation/).
