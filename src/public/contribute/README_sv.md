# Bidra

Du kan hjälpa till att bygga och testa Samizdat-applikationen. Klona arkivet från
[https://github.com/FAKEMedium/Samizdat.git](https://github.com/FAKEMedium/Samizdat.git)

### Hitta video, ljud och bilder

Lägg till mediakällor med en git pull request. Du kan också använda [kontaktsidan](../contact/) för att skicka in.
Lär dig om formatet och hur du skriver innehållsextraktorer.

### Översättningar

Hjälp till att översätta dokument och skript. Lägg till en rysk översättning av README.md genom att skapa README.ru.md i samma
katalog. Skript- och mallfiler översätts i po-filer i locale-källkatalogen.
